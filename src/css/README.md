# css

One stylesheet per concern, not a monolithic file. Every color as a CSS custom property on `:root`, with `data-theme` light/dark overrides set before first paint — matching `OrgVisualizr/agents.md`'s "Theming" convention — applied to the Issue-shell chrome, independent of whatever theming each embedded engine (bpmn-js/draw.io/Mermaid) supports natively.

Sibling-project convention, see `agents.md`.
