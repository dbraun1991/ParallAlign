# shell/issue-sidebar

Left panel: searchable list of Issues (title + theme/state), resizable via the drag-handle mechanism from `bpmn-process-creator`, mobile `<details>`/`<summary>` collapse from `Climb-Buddy-Belay`. Selecting an Issue loads its five canvases and resets the shell to All + expanded Backlog panel.

ADR-0007, ADR-0008.
